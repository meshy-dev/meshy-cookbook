# Epic AI MegaJam: dated release reference

Checked 2026-11-10 against [Epic's event page](https://itch.io/jam/2026-epic-ai-megajam) and
[5.9 MegaJam Preview announcement](https://forums.unrealengine.com/t/unreal-engine-5-9-megajam-preview/2852840).
Recheck the event page and its linked Official Rules when giving submission advice. These notes
support asset preparation; they don't certify eligibility or authorize uploading a submission.

The event runs November 12–15, 2026. The listed deadline is November 15 at 5:59 PM Pacific
(6:59 PM America/Denver). Set up tools before kickoff; declare assets made earlier. Record actual
creation times and source provenance, not a default jam date. Epic accepts Unreal and UEFN entries,
but this skill targets Unreal Editor and doesn't establish UEFN compatibility.

The listed Meshy perk is a free month of Pro with 1,000 credits for a new account through the
jam's claim link, redeemable by November 17; the page says a credit card is required. Link users
to that current listing rather than promising every existing account is eligible. Balance and
API entitlement still need checking before paid work. Never redeem or subscribe for the user.

For Unreal entries, the event page calls for a packaged game and a 30–60 second gameplay video;
unpackaged project folders aren't accepted. Web uses a Shipping build; the page lists a 500 MB
total/200 MB per-file limit and `index.html` at the archive root. Desktop/mobile archives under
1 GB use the ordinary upload path; the page gives uploader alternatives for larger builds.
Choose asset budgets with the target in mind and leave time to package/test. Verify current
requirements before preparing a final submission.

## Provenance export

When requested, write `MeshyAssets/ASSETS.md` from the revision records, including:

- Asset name, final Unreal paths and accepted revision, plus retained variants where relevant.
- Actual creation timestamp and known input/source dates; mark pre-jam material against the
  event cutoff. Unknown historical dates stay unknown.
- Exact submitted prompt/settings and source-image/file/task lineage, from immutable records.
- Meshy operations, task IDs and known credit usage; separate unknown values from zero.
- Local edits and outside assets used, with their source/license information when available.

Do not recalculate old prompts from the current style line. This detailed provenance is useful
project documentation, not a claim that every prompt/credit field is mandatory for entry. The
event summary requires disclosure of earlier/external assets; its tools-used field is optional
but relevant to some partner prizes. Point to the current rules for the final submission fields.
