# Sample concept image

`sea-chest.png` is the concept image cookbook 03 generated with the Meshy text-to-image API (`gpt-image-2-5-sunburst`, `remove_background: true`) on 2026-09-21, copied unmodified from that recipe's published preview (`examples/03-text-to-hero-prop/assets/concept.png`, SHA-256 `17db5aad1fa4a5d3a24630214f56e124de768ff8a6a712bfa414ae4d3161be23`). It is a 1024 × 1024 PNG with a transparent background. It is Meshy-owned; use it freely to try the cookbook. The README calls it the sea chest.

Prompt: Marrow's sea chest, a closed pirate treasure chest: weathered oak planks, black iron straps and rivets, a heavy brass padlock, barnacles along the base. Stylized hand-painted game prop, three-quarter view.

The model stage of this recipe sends it through the same textured image-to-3d request as cookbook 01, so the dense model that gets simplified is the chest from cookbook 03 built at the default geometry and texture resolution.
