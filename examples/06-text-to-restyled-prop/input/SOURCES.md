# Sample concept image

`low-poly-oak.png` is the same image as cookbook 02's sample. It was generated with the Meshy text-to-image API (`nano-banana`, `remove_background: true`) on 2026-09-21 and is a 1024 × 1024 PNG with a transparent background. It is Meshy-owned; use it freely to try the cookbook. The README calls it the oak.

Prompt: A single stylized oak tree with a short thick trunk and three rounded canopy clumps. Stylized low-poly game asset, flat-shaded faceted polygons, clean silhouette, soft even lighting, three-quarter view, plain white background, no ground plane, no text.

The model stage of this recipe sends it through the same Smart Topology request as cookbook 02, so the gray mesh that gets restyled is the low-poly oak from that recipe.
